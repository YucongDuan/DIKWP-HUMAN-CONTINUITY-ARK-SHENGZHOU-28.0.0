# Family Trust and Deepfake Protocol / 家庭信任与深度伪造协议

## Five-step protocol / 五步协议

1. **Pause / 停止**：任何要求保密、立即转账、提供验证码、改变地点或代替本人签约的消息，一律先停止。
2. **Break the channel / 断开原通道**：挂断、退出聊天或停止屏幕共享，不使用对方发来的回拨号码。
3. **Call back independently / 独立回拨**：使用纸质通讯录、既有联系人或官方网页上的号码。
4. **Private challenge / 私密挑战**：询问一项公开资料和社交媒体无法轻易得到的共同经历；不要把真实答案存入本客户端。
5. **Second trusted person / 第二可信人**：涉及钱、迁移、医疗、法律或身份时，至少再由一名可信人确认。

## What not to use as sole proof / 不能单独作为证明的信号

- 声音相似；
- 视频中出现熟悉面孔；
- 来电显示；
- 对方知道公开家庭信息；
- 一张“官方文件”截图；
- 以紧急、羞耻、权威或保密为理由阻止核验。

## Recovery after a mistake / 误操作后的恢复

立即联系真实机构、冻结或限制账户、保留原始证据、改变关键凭证、通知可能受影响的人，并记录哪一道核验机制失效。目标是恢复和学习，不是羞辱受骗者。
