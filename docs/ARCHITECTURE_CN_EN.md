# SHENGZHOU 28 Architecture / 生舟28架构

## 中文

### 1. 治理对象

生舟治理的不是一个孤立模型，而是个人所处的完整能力系统：

```text
人 + 家庭 + AI模型 + Agent + 工具 + 账户 + 身份 + 支付 + 云服务 + 通信 + 公共服务 + 本地关系
```

失控可能并不以“AI公开宣布敌意”开始，而可能以错误授权、自动续权、身份冒用、深度伪造、推荐操纵、支付冻结、云端中断、服务供应断裂或收入快速压缩开始。

### 2. 九层架构

1. **家庭连续性护照**：家庭成员、依赖者、宠物、辖区和不可牺牲底线。
2. **十二底线测量层**：把准备度拆成十二个互不抵消的维度。
3. **八世界压力实验室**：在非同构失效世界中检验同一家庭状态。
4. **信号与触发器**：将可观察信号编译为L0-L4模式。
5. **AI权限防火墙**：区分“可以做”和“有权做”。
6. **家庭信任协议**：独立回拨、私密挑战、第二可信人和会合点。
7. **行动编译器**：按风险、成本和现实增益生成有限任务。
8. **演练与现实接触**：通信、身份、支付、健康和迁移演练。
9. **回执与连续性包**：保存版本、结果、纠正和哈希链。

### 3. 非补偿底线

设十二维底线为：

\[
F=(S,H,Sh,C,I,Fi,D,Inf,A,M,Co,Psy)
\]

稳健连续性不是平均值，而是：

\[
R=\min_{w\in W}\min_{d\in F} f_{d,w}
\]

所以某个领域的高分不能掩盖另一个领域归零。

### 4. 现实闭环

```text
准备状态 -> 多世界压力 -> 最弱底线 -> 有限行动
-> 演练 -> 现实结果 -> 纠正 -> 新版本 -> 回执链
```

## English

SHENGZHOU governs the whole personal capability system rather than a model in isolation. It uses nine layers: Household Continuity Passport, twelve non-compensatory floors, eight disruption worlds, signal triggers, an AI Authority Firewall, a family trust protocol, an action compiler, drills with reality contact, and versioned receipts/packages.

Its robust floor is the minimum capability retained across every essential domain and every modeled world. A strong average cannot hide the complete loss of medicine, identity, communications or human authority.
