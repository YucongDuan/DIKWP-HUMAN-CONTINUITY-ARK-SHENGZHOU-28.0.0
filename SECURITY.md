# Security

Do not enter passwords, authentication codes, private keys, seed phrases, complete identity documents,
medical records, exact family codewords, or other secrets into the browser client. The client stores data
locally in the browser and is not a secure vault.

Report a security issue privately to the repository maintainer before public disclosure. Include the
version, affected file, reproduction steps, expected behavior and actual behavior. Do not test against
third-party systems without explicit authorization.
